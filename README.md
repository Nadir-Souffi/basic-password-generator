Password Toolkit
A lightweight basic modular Python GUI application for generating secure random passwords and evaluating password strength. Built with standard `tkinter` and modular Python logic.

basic-password-generator/
├── app.py                      # Main Tkinter GUI interface
├── password_generator_logic.py # Pure Python password generation logic
├── password_checker_logic.py   # Pure Python strength evaluation logic
├── .gitignore                  # Git exclusion rules
└── README.md                   # Project documentation
